## 划分泄漏结论

17 组字节级重复图像中，5 组跨 Train–Validation，5 组跨 Train–Test，0 组跨 Validation–Test；另有 1 组在 Test 内部重复。4 组属于同图不同掩膜。

冻结权重的只读敏感性复算表明，排除 5 个已知 Train–Test 重复测试记录后，FPN Recall/AUPRO 从 0.4481/0.3476 变为 0.4434/0.3421，RC-FPN（sigma=1）从 0.6277/0.5774 变为 0.6069/0.5691。该结果只能说明影响方向和量级，不能作为修正后正式指标，因为训练暴露和验证集选模泄漏仍存在。

使用授权数据训练或评价前，必须运行：

```bash
python scripts/audit/check_split_leakage.py --split-dir 私有划分目录
```

正式修正需要按采集来源/内容组建立互斥划分并重新训练全部比较方法。
